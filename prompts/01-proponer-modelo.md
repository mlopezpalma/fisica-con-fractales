# Proponer un modelo

```text
Tengo trayectorias de partículas en un gel (2D, 200 puntos cada una,
20 ms entre puntos). El desplazamiento cuadrático medio crece como
t^0,6 hasta 1 s.
1. Propón dos o tres modelos físicos compatibles (CTRW, fBm,
   difusión en un fractal...).
2. Para cada uno, di qué medida los distingue.
3. No des números que no te haya dado yo.
4. Dime qué funciones de fractales_fisica usaría para simular cada
   modelo y comprobar tu propuesta.
```

Después: simula cada modelo (`aleatorio.ctrw_msd`, `aleatorio.fbm`) y compara con tus datos. Ver [índice](README.md).
