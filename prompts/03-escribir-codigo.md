# Escribir código con una prueba

```text
Escribe una función de Python que calcule la dimensión de conteo de
cajas de una imagen binaria con NumPy. Requisitos: tamaños de caja en
potencias de 2, ajuste por mínimos cuadrados en log-log, devuelve D y
R². Añade una prueba con el triángulo de Sierpinski de nivel 8, cuyo
resultado debe ser log 3 / log 2.
```

La prueba con un fractal de dimensión conocida es la mitad de la instrucción. Ver [índice](README.md).
