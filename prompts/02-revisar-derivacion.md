# Revisar una derivación

```text
Revisa esta derivación paso a paso. Señala cada error de unidades,
de signo o de lógica, y cada paso que necesite una hipótesis que no
esté dicha. No la reescribas entera.
[pega aquí la derivación]
```

Por qué «no la reescribas»: una reescritura puede introducir errores nuevos que parezcan correcciones. Comprueba cada objeción con un caso límite (α = 1, D entero) o con el simulador. Ver [índice](README.md).
