# Instrucciones para la IA (capítulo 16)

Plantillas para usar un asistente de IA con el simulador. Regla común: **la IA propone, el simulador comprueba**. Pasa los datos como texto (no como imagen) y no pegues datos personales ni confidenciales.

- [01-proponer-modelo.md](01-proponer-modelo.md): proponer modelos físicos compatibles con unos datos.
- [02-revisar-derivacion.md](02-revisar-derivacion.md): señalar errores en una derivación sin reescribirla.
- [03-escribir-codigo.md](03-escribir-codigo.md): escribir código con una prueba de verdad conocida.
- [04-explicar-resultado.md](04-explicar-resultado.md): la instrucción de sistema que usa el paquete para explicar resultados.
